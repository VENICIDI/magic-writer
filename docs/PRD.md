## 一、产品概览

### 1.1 一句话定义

**Magic Writer** —— 面向网文作者的 AI 驱动独立桌面写作工具。

> "让 AI 成为你的责编、大纲助理和文笔教练，而不是替你写。"

### 1.2 产品形态

| 属性 | 描述 |
|---|---|
| 形态 | 独立桌面应用（macOS / Windows / Linux） |
| 技术底座 | Electron + React + Monaco Editor |
| 核心能力 | 多 Agent 协作（续写 / 润色 / 审校 / 大纲 / 世界观） |
| 数据策略 | 本地优先，隐私安全，云端可选 |
| 商业模式 | Freemium（免费本地 + Pro 订阅） |

### 1.3 产品愿景

打造网文创作领域的 **"Cursor for Writers"**：

- **专业**：不是通用 AI 聊天框改装，而是专为长篇小说设计的完整创作工作流
- **记忆**：结构化世界观 + RAG 语义检索，百万字仍记住第一章的伏笔
- **性能**：本地原生，百万字 60fps 编辑，离线可用
- **尊重**：作品不上云，AI 辅助而非替代，去 AI 味

## 二、目标用户与核心场景

### 2.1 用户画像

| 层级 | 用户画像 | 规模 | 核心痛点 |
|---|---|---|---|
| **P0** | 网文连载作者（日更 3k-1w 字） | 50w+ | 卡文、人设崩、伏笔忘、水字数被喷 |
| **P1** | 兼职写手 / 新人 | 200w+ | 不会写大纲、文笔生硬、不知道爽点节奏 |
| **P2** | 编剧 / 游戏剧情策划 | 10w+ | 多线叙事混乱、人物关系复杂、团队协作 |

### 2.2 用户旅程

#### 旅程一：首次使用 → 产出第一章

```
下载安装 → 创建项目 → 输入一句话设定 → AI 生成世界观 + 大纲
→ 打开第一章 → AI 流式续写初稿 → 选区润色 → 保存
```

#### 旅程二：日更工作流

```
打开应用 → 自动定位到最新章节 → 查看今日目标字数
→ 浏览本章大纲 → 续写（AI 辅助 + 手工修改交替）
→ 达到目标字数 → 庆祝动画 → 保存 → 后台增量索引
```

#### 旅程三：写到 50 万字时的复盘

```
打开项目 → 审校 Agent 扫描全书 → 输出冲突报告
→ 点击跳转到有问题的段落 → 查看修复建议 → 一键应用 / 手工修改
→ 查看人物关系图 → 查看伏笔回收表 → 标记已回收伏笔
```

## 四、非功能性需求

### 4.1 性能指标

| 指标 | 目标 | 备注 |
|---|---|---|
| 冷启动 | < 2 秒 | 首屏只渲染编辑器 |
| 百万字编辑 | 60fps 滚动 | Monaco viewport 渲染 + 分文件 |
| 流式续写延迟 | 首 token < 500ms | LLM 端决定 |
| RAG 检索 | P99 < 50ms | LanceDB HNSW |
| 保存 | < 50ms | SQLite WAL 模式 |
| 内存占用 | < 400MB 常态 | 非当前章节懒加载 |

### 4.2 兼容性

| 平台 | 版本要求 | 打包格式 |
|---|---|---|
| macOS | 12+ (Monterey) | DMG (x64 + arm64) |
| Windows | 10 1903+ | NSIS installer |
| Linux | Ubuntu 20.04+ | AppImage |

### 4.3 数据安全

- 作品默认本地存储，不联网
- 云同步采用端到端加密
- BYOK 模式下 LLM 请求不经我方服务器
- 隐私协议明确声明：**不训练用户数据**

## 五、竞品分析

| 维度 | Scrivener | 橙瓜码字 | 笔趣 AI | ChatGPT/Claude | **Magic Writer** |
|---|---|---|---|---|---|
| 平台 | 桌面 | 桌面+移动 | Web | Web | **桌面** |
| AI 能力 | ❌ 无 | 基础续写 | 续写+润色 | 通用 AI | **专业多 Agent** |
| 长文记忆 | 手工管理 | ❌ | 弱 | ❌ 上下文丢 | **RAG + 世界观** |
| 一致性审校 | ❌ | ❌ | ❌ | ❌ | **✅ 核心壁垒** |
| 性能 | 优秀 | 一般 | 网页卡 | 网页 | **原生优秀** |
| 数据隐私 | ✅ 本地 | ❌ 云端 | ❌ 云端 | ❌ 云端 | **✅ 本地优先** |
| 价格 | 买断 ¥348 | 订阅 ¥30/月 | 免费+广告 | $20/月 | **Freemium** |
| 去 AI 味 | - | 弱 | 弱 | 无 | **风格学习** |

### 核心竞争壁垒

1. **ReviewAgent 审校能力** —— 市面上唯一能做人设一致性 + 时间线 + 伏笔冲突检测的写作工具
2. **本地优先 + BYOK** —— 唯一同时满足隐私需求和 AI 能力的独立桌面方案
3. **作者社区** —— 通过模板市场、风格包建立创作者生态

| 风险 | 影响 | 概率 | 对策 |

| 模型能力退化 | 质量波动 | 中 | 多模型降级 + A/B 评测 |
