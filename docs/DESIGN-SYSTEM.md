## 一、设计哲学

### 1.1 核心设计原则

| 原则 | 释义 | 设计体现 |
|---|---|---|
| **🖋️ 文字至上** | 一切为文字让路，UI 是配角 | 极简深色背景、无装饰边框、大留白 |
| **🌙 夜间友好** | 作者常深夜创作，护眼第一 | 低对比深色系、护眼暖色光标 |
| **🎯 专注即正义** | 写作模式零干扰 | 打字机滚动、渐隐侧栏、呼吸感动效 |
| **🤖 AI 若即若离** | AI 随叫随到但不喧宾夺主 | Agent 面板默认收于右侧，不自动弹出 |
| **⚡ 响应如飞** | 本地原生应有的速度感 | 60fps 滚动、流式逐字、即时反馈 |

### 1.2 情感基调

```
                    宁静         专注         温暖
                     │           │           │
                     ▼           ▼           ▼
              ┌──────────────────────────────────────┐
              │     深邃星空 × 墨水质感 × 微光点缀    │
              │     ─────────────────────────────     │
              │     像在一间暗色书房里，台灯照亮稿纸   │
              └──────────────────────────────────────┘
```

**品牌气质**：不是冰冷的代码编辑器，也不是花哨的笔记应用。是一间深夜书房——安静、沉浸、有温度。

## 二、色彩系统

### 2.1 主色板（深色模式 · 默认）

| Token | 色值 | 用途 |
|---|---|---|
| `surface-900` | `#0a0a12` | 主背景、编辑区底色 |
| `surface-800` | `#0f0f1a` | 侧栏底色、标题栏 |
| `surface-700` | `#161625` | 输入框底色、卡片背景 |
| `surface-600` | `#1e1e30` | 分隔线、hover 态 |
| `surface-500` | `#2a2a3d` | disabled 态、次要边框 |
| `accent` | `#7c3aed` | 主强调色（按钮、高亮） |
| `accent-light` | `#a78bfa` | 选中态、链接、光标 |
| `text-primary` | `#e2e8f0` | 正文文字 |
| `text-secondary` | `#94a3b8` | 次要文字 |
| `text-muted` | `#64748b` | 提示文字、placeholder |
| `success` | `#22c55e` | 保存成功、目标达成 |
| `warning` | `#f59e0b` | 未保存、注意提醒 |
| `error` | `#ef4444` | 错误、冲突 |
| `info` | `#3b82f6` | 信息提示 |

### 2.2 语义色彩映射

```
┌─────────────────────────────────────────────┐
│ Agent 类型色彩                                │
├─────────────┬───────────────────────────────┤
│ Writer 续写 │ accent (#7c3aed)              │
│ Polish 润色 │ emerald (#10b981)             │
│ Review 审校 │ amber (#f59e0b)               │
│ Outline 大纲│ sky (#0ea5e9)                 │
│ World 世界观│ rose (#f43f5e)                │
└─────────────┴───────────────────────────────┘
```

### 2.3 对比度要求

- 正文：最小 `7:1`（WCAG AAA）
- 次要文字：最小 `4.5:1`（WCAG AA）
- 交互元素：最小 `3:1`（WCAG AA）

### 2.4 浅色模式（未来规划）

预留浅色主题 token 命名：`light-surface-*`，V2.0 支持切换。设计时深色优先，但组件不硬编码色值。

## 三、排版系统

### 3.1 字体选择

| 层级 | 字体栈 | 场景 |
|---|---|---|
| **编辑器正文** | `'LXGW WenKai', 'Noto Serif SC', 'PingFang SC', serif` | Monaco 内的写作字体 |
| **UI 界面** | `'Inter', 'PingFang SC', 'Microsoft YaHei', sans-serif` | 侧栏、面板、按钮 |
| **代码/等宽** | `'JetBrains Mono', 'Fira Code', monospace` | 设置项、JSON 大纲 |

### 3.2 字号体系

| Token | 大小 | 行高 | 用途 |
|---|---|---|---|
| `text-xs` | 10px | 14px | 标签、角标 |
| `text-sm` | 12px | 18px | 侧栏条目、状态栏 |
| `text-base` | 14px | 22px | Agent 对话、面板正文 |
| `text-lg` | 16px | 28px | 编辑器正文（常规） |
| `text-xl` | 18px | 32px | 编辑器正文（写作模式） |
| `text-2xl` | 24px | 36px | 章节标题 |
| `text-3xl` | 30px | 40px | 项目标题 |

### 3.3 编辑器排版参数

```typescript
// 常规模式
fontSize: 16,
lineHeight: 28,    // 1.75 倍行高，网文阅读舒适
padding: { top: 24, bottom: 160 },

// 写作模式
fontSize: 18,
lineHeight: 32,    // 更宽松，沉浸感
// 居中栏宽 ≤ 680px
```

### 3.4 中文排版规范

- 段落首行不缩进（网文惯例）
- 段落间距：`1em`（空行分段）
- 引号使用中文「」、""
- 数字 / 英文使用半角字符
- 省略号使用 `……`（两个三点）

### 4.3 写作模式布局

```
┌────────────────────────────────────────────────────────┐
│                                                        │
│                                                        │
│            ┌───────────────────────┐                   │
│            │                       │                   │
│            │   编辑区 (max 680px)   │                   │
│            │   居中，上下大留白      │                   │
│            │                       │                   │
│            │   打字机：当前行居中    │                   │
│            │                       │                   │

│                                                        │
```

- 隐藏所有侧栏
- 编辑区居中，最大栏宽 680px
- 顶部 / 底部各留 `20vh` 呼吸空间
- 底部浮动：半透明字数进度条
- 背景纯黑 `#0a0a12`

### 4.4 响应式策略

桌面应用不需移动端适配，但需考虑：

| 场景 | 行为 |
|---|---|
| 窗口 < 1000px | 自动折叠左侧栏 |
| 窗口 < 800px | 自动折叠右侧栏 |
| 分屏模式 | 保证编辑区 > 400px |

## 七、动效规范

### 7.1 设计原则

> **动效是情绪的呼吸，不是注意力的劫持。**

- 快：界面切换 150ms 内完成
- 轻：不使用 bounce、弹性等跳跃感动效
- 静：写作过程中零主动动画干扰

### 7.2 动效一览

| 场景 | 动效 | 时长 | 缓动 |
|---|---|---|---|
| 侧栏折叠/展开 | width transition | 200ms | ease-out |
| 按钮 hover | background-color | 150ms | ease |
| Agent 切换 | opacity fade | 150ms | ease |
| 流式文字出现 | 逐字追加（无淡入） | 实时 | - |
| 生成中光标 | pulse 闪烁 | 1000ms | ease-in-out |
| 保存成功 | 状态色变绿 | 200ms | ease |
| 写作模式切换 | 侧栏 slideOut + 编辑区居中 | 300ms | ease-in-out |
| 目标达成庆祝 | confetti 粒子 | 2000ms | 自定义 |
| 命令面板弹出 | scale(0.95→1) + opacity | 150ms | ease-out |
| 命令面板关闭 | opacity fadeOut | 100ms | ease-in |

### 7.3 流式续写动效

```
文字逐字出现（token 级）
  ├─ 无额外淡入效果（避免掉帧）
  ├─ 尾部光标 block (accent-light, 6×14px)
  ├─ 光标 pulse 动画
  └─ 完成后光标消失 (opacity 0, 300ms)
```

### 7.4 写作模式转场

```
进入写作模式:
  1. 左侧栏 → 向左 slide + fade (200ms)
  2. 右侧栏 → 向右 slide + fade (200ms)
  3. 编辑区 → 居中 + 收窄至 680px (300ms)
  4. 状态栏 → 缩为浮动字数条 (200ms)

退出:
  反向播放，时长一致
```

## 八、写作模式深度设计

### 8.1 核心体验

写作模式是 Magic Writer 的 **灵魂体验**。目标：

> 让作者进入心流状态，忘记工具的存在。

### 8.2 打字机滚动

```
┌────────────────────────────────┐
│                                │
│         (上方灰化内容)          │
│                                │
│ ─────── 视口中央线 ────────── │
│                                │
│     ▎ 当前光标行始终在此       │
│                                │
│         (下方空白)              │
│                                │
└────────────────────────────────┘
```

- 光标所在行始终保持在视口垂直中心
- 滚动使用 `smoothScrolling`
- 上方已写内容：正常可见
- 下方留白至少 `50vh`

### 8.3 环境音（M2 规划）

| 音景 | 描述 |
|---|---|
| 深夜雨声 | 舒缓白噪音 |
| 咖啡馆 | 轻微人声杂音 |
| 火堆 | 温暖静谧 |
| 森林 | 鸟鸣风声 |
| 无声 | 默认 |

音量控制：状态栏小按钮，不打断写作。

### 8.4 字数目标与庆祝

```
┌──────────────────────────────────────────┐
│                                          │
│          今日已写 3,240 / 5,000          │
│     ████████████████░░░░░░░  64.8%      │
│                                          │
└──────────────────────────────────────────┘
```

- 进度条半透明浮于底部
- 颜色渐变：`gray → accent → success`
- 达到目标时：confetti 粒子从底部升起 + 短暂弹出 "🎉 目标达成！"
- 2 秒后自动消失

## 九、Agent 交互设计

### 9.1 交互模式

| 模式 | 触发方式 | 场景 |
|---|---|---|
| 面板对话 | Agent 面板输入框 + ⌘Enter | 通用：续写、提问、大纲 |
| 选区操作 | 选中文字 → ⌘L / 右键菜单 | 润色、改写、缩写 |
| 行内建议 | ⌘. 或 AI 主动（可关闭） | 类 Cursor Tab 补全 |
| 命令面板 | ⌘K → 输入指令 | 快捷操作 |

### 9.2 面板对话 UX

```
┌─ Agent Panel ─────────────────────────┐
│                                       │

│ │                                   │ │

│ │ [writer]                          │ │

│ │                                   │ │
│ └───────────────────────────────────┘ │
│                                       │
│ ┌─ Input ───────────────────────────┐ │

│ │                                   │ │
│ │                                   │ │
│ └───────────────────────────────────┘ │
│ ┌──────────────────────────────────┐  │

│ └──────────────────────────────────┘  │
└───────────────────────────────────────┘
```

### 9.3 续写写入编辑器

当 Writer 模式续写时：

1. Agent 面板显示对话流（正常）
2. **同时** 流式文本实时追加到 Monaco 编辑器末尾
3. 编辑器自动滚动跟随
4. 用户可随时点击编辑器停止追加

视觉指示：
- 编辑器光标变为 `accent-light` 色 block
- 状态栏显示 "✍️ AI 续写中…"

### 9.4 选区润色交互（M1）

```
1. 用户选中文字
2. 浮现工具条：[润色] [缩写] [扩写] [换风格]
3. 点击后 → Agent 面板切换到 Polish
4. 返回结果以 inline diff 展示
5. 用户选择 [采纳] 或 [放弃]
```

Diff 样式：
- 删除内容：`line-through + text-red-400/50`
- 新增内容：`text-green-400 + underline`

### 10.1 人物卡设计

## 十一、间距与网格

### 11.1 间距体系

采用 **4px 基准网格**：

| Token | 值 | 用途 |
|---|---|---|
| `space-1` | 4px | 图标与文字间距 |
| `space-2` | 8px | 元素内边距 |
| `space-3` | 12px | 面板内边距 |
| `space-4` | 16px | 模块间距 |
| `space-5` | 20px | 大留白 |
| `space-6` | 24px | 编辑区顶部 padding |
| `space-8` | 32px | 标题栏高度 |

### 11.2 圆角

| Token | 值 | 用途 |
|---|---|---|
| `rounded-sm` | 4px | 导航项、标签 |
| `rounded-md` | 6px | 小按钮 |
| `rounded-lg` | 8px | 按钮、对话气泡、卡片 |
| `rounded-xl` | 12px | 命令面板、弹窗 |
| `rounded-full` | 50% | 头像、状态点 |

## 十二、无障碍设计

### 12.1 键盘导航

- 所有交互元素可通过 Tab 聚焦
- 命令面板支持方向键 + Enter
- 侧栏树支持方向键展开/折叠/选择
- ESC 关闭所有浮层

### 12.2 屏幕阅读器

- 语义化 HTML：`nav`、`main`、`aside`、`footer`
- 关键状态使用 `aria-label`
- 动态内容使用 `aria-live`

### 12.3 运动敏感

- 提供 `prefers-reduced-motion` 适配
- 在该模式下：禁用 confetti、缩短所有 transition 至 0

## 十四、设计原则速查

> 留给开发团队在实现时快速参考的判断标准。

| 当你犹豫时… | 选择… |
|---|---|
| 加一个装饰 vs 留白 | **留白** |
| 亮色 vs 暗色 | **暗色** |
| 粗边框 vs 无边框 | **无边框或 1px surface-600** |
| 动效华丽 vs 动效克制 | **克制** |
| AI 主动弹出 vs 用户主动唤起 | **用户唤起** |
| 功能入口明显 vs 隐藏 | **先隐藏，⌘K 可达** |
| 自定义组件 vs 原生外观 | **原生优先，保持一致** |
| 信息密集 vs 渐进展开 | **渐进展开** |
