# Magic Writer 产品设计文档

> 一款面向网文作者、编剧、剧情策划的 AI 驱动的**独立桌面写作软件**。
> 形态借鉴 Scrivener × Cursor × Notion，但专注于长篇小说创作场景。

---

## 1. 产品概述

### 1.1 产品定位
**Magic Writer** —— 独立桌面端 AI 小说创作工具。

一句话定义：**"让 AI 成为你的责编、大纲助理和文笔教练，而不是替你写。"**

### 1.2 核心差异化

| 维度 | Scrivener / 橙瓜码字 | ChatGPT/通用 AI | Cursor (代码类比) | **Magic Writer** |
|---|---|---|---|---|
| 专业度 | 高，但无 AI | 低，易串味 | 写代码强，不写小说 | 专为小说设计 |
| 长程记忆 | 手工 | 上下文丢 | - | 结构化世界观+RAG |
| 工作流 | 纯编辑 | 单轮对话 | Agent 化 | 多 Agent 小说工作流 |
| 桌面性能 | 原生好 | 网页卡 | 原生好 | 原生 + 百万字流畅 |
| 形态 | 桌面 | 网页 | 桌面 | **独立桌面应用** |

### 1.3 为什么做独立桌面端（而非扩展 / Web）

| 选项 | 优势 | 劣势 | 决策 |
|---|---|---|---|
| Web 应用 | 免安装 | 长文档卡、离线不可用、隐私差 | ❌ |
| VSCode 扩展 | 开发快 | 用户心智是程序员、UI 被限制、品牌弱 | ❌ |
| **独立桌面应用** | **品牌/体验/性能/隐私全占** | 开发成本高、需自建更新体系 | ✅ |

独立桌面端能做到：
- **作者友好的 UI**：写作模式专属布局，而非"改装过的 IDE"。
- **原生性能**：本地文件直读、SQLite 同步 IO、百万字编辑不卡。
- **完全可定制**：快捷键、主题、工具栏、工作流均围绕写作设计。
- **数据主权**：作品存本地，AI 可选本地模型，符合作者对版权的敏感度。
- **独立品牌**：直接触达网文圈，无需寄生生态。

## 2. 目标用户与场景

### 2.1 用户画像
- **P1 网文连载作者**：日更 3k-1w 字，痛点"卡文 / 人设崩 / 伏笔忘 / 水字数被差评"。
- **P2 兼职写手 / 新人**：需大纲模板、文笔润色、爽点节奏指导。
- **P3 编剧 / 游戏剧情策划**：多线叙事、人物关系图、分支剧情。

### 2.2 核心场景
1. **冷启动**：一句话设定 → 世界观 → 大纲 → 第一章初稿。
2. **日更**：基于前文一致性续写当前章节。
3. **修改**：选中段落 → 润色 / 改风格 / 扩写 / 缩写。
4. **复盘**：自动生成人物关系图、时间线、伏笔回收表。
5. **连载**：一键发布到起点 / 番茄 / 公众号。

## 4. Agent 架构设计

### 4.1 多 Agent 协作流

```
              用户输入（自然语言 / 快捷键 / 选区 / 右键菜单）
                              │
                              ▼
                   ┌──────────────────────┐
                   │   Router Agent        │  意图识别，任务分发
                   └──────────┬────────────┘
                              │
     ┌───────────┬────────────┼────────────┬───────────┐
     ▼           ▼            ▼            ▼           ▼
 ┌────────┐ ┌────────┐   ┌────────┐   ┌────────┐ ┌────────┐
 │Outline │ │ Writer │   │ Polish │   │ Review │ │ World  │
 │大纲    │ │续写    │   │润色    │   │审校    │ │世界观  │
 └────┬───┘ └────┬───┘   └────┬───┘   └────┬───┘ └────┬───┘
      └──────────┴─────────────┴─────────────┴──────────┘
                              │
                              ▼
                   ┌──────────────────────┐
                   │  Context Builder      │  RAG + 人物卡 + 近文
                   └──────────┬────────────┘
                              ▼
                   ┌──────────────────────┐
                   │   LLM Gateway         │  多模型路由 + 降级
                   └──────────────────────┘
```

### 4.2 核心 Agent 说明

**OutlineAgent（大纲）**
- 输入：题材 / 主角 / 卖点 / 目标字数
- 输出：三幕 → 分卷 → 分章梗概（JSON，可迭代）
- 内建模板：爽文曲线 / 悬疑螺旋 / 言情节奏

**WriterAgent（续写）—— 最高频入口**
- 上下文策略：`前 N 章全文（token 裁剪） + 本章大纲 + 人物卡 + RAG 检索 + 最近 3k 字`
- Token 级流式，支持随时打断、接力、回退 N 字重写

**PolishAgent（润色）**
- 模式：文笔 / 节奏 / 对话 / 环境 / 去口水话 / 换风格
- 严格保留原语义，diff 视图展示改动

**ReviewAgent（审校）—— 产品核心壁垒**
- **人设一致性**：性格 / 口头禅 / 能力边界
- **时间线**：出场时间 / 地点 / 年龄
- **伏笔**：埋点章节 → 回收章节追踪
- 输出：可跳转的冲突报告 + 修复建议

**WorldAgent（世界观）**
- 从正文自动抽取实体（人物 / 地点 / 势力）入库
- 用户可锁定字段，禁止 Agent 修改

## 5. 技术架构

### 5.1 技术栈

| 层 | 技术选型 | 选型理由 |
|---|---|---|
| **桌面框架** | **Electron** | 跨平台、生态成熟、与 Monaco 天然契合 |
| 渲染进程 UI | React 18 + TypeScript | 生态 + 类型安全 |
| 构建工具 | Vite + electron-vite | 冷启动快、HMR 丝滑 |
| 编辑器内核 | **Monaco Editor** | 百万字级性能、VSCode 同款 |
| 状态管理 | Zustand | 轻量、无样板 |
| UI 组件 | Radix UI + Tailwind | 可访问性 + 高度定制 |
| 可视化 | ReactFlow（关系图）/ ECharts（统计） | 业界标准 |
| 进程通信 | Electron IPC + EventEmitter | 原生 |
| **主进程** | Node.js（Electron 内置） | - |
| **本地存储** | better-sqlite3（同步、快） | 元数据 |
| **向量库** | **LanceDB**（嵌入式 Rust） | 本地 100w 向量 P99 < 50ms |
| 全文检索 | SQLite FTS5 | 零依赖 |
| LLM 接入 | 自建 Gateway，适配 OpenAI / Anthropic / DeepSeek / Ollama / vLLM | 解耦、降级 |
| Embedding | bge-m3（本地） / text-embedding-3（云） | 中文效果好 |
| 流式渲染 | IPC stream + `requestAnimationFrame` 批处理 | 60fps 逐字渲染 |
| 打包 | electron-builder | Win / macOS / Linux |
| 自动更新 | electron-updater（S3/自建） | - |
| 崩溃日志 | Sentry（可选） | - |
| 本地模型 | Ollama 本地部署（集成引导安装） | 隐私 + 离线 |

### 5.2 为何选 Electron（而非 Tauri / Flutter）

| 维度 | Electron | Tauri | Flutter Desktop |
|---|---|---|---|
| Monaco 集成 | **原生支持** | 需 WebView2 兼容 | 无对应方案 |
| Node 生态 | 完整 | 需 Rust 后端 | 需 FFI |
| 包体积 | 大（~120MB） | 小（~15MB） | 中 |
| 性能 | 够用（可优化至原生级） | 更优 | 优 |
| 开发速度 | 最快 | 中 | 慢 |
| 团队门槛 | Web 技术栈 | 需 Rust | 需 Dart |
| 结论 | ✅ MVP 首选 | 未来演进方向 | 不适合文档密集场景 |

**决策**：Electron 起步，关键路径（如向量检索、全书分析）用 Rust Native Module 加速。

### 5.3 性能关键设计

1. **编辑器**：Monaco 的 viewport 渲染 + 按章节分文件（单文件 ≤ 5w 字），100w 字小说滚动 60fps。
2. **冷启动 < 2s**：主进程懒加载非核心模块；首屏只渲染编辑器。
3. **RAG**：LanceDB 嵌入式 + HNSW，P99 < 50ms；Embedding 本地化。
4. **流式写作**：token 级 IPC，Webview 批处理 DOM。
5. **进程隔离**：重型任务（全书审校、批量 Embedding）走独立 Worker 进程，主线程零阻塞。
6. **增量索引**：按 chunk hash 判断变更，仅重 Embed 变更段落。
7. **内存控制**：非当前章节 Markdown 懒加载；LRU 缓存保留最近 10 章。
8. **磁盘 IO**：SQLite WAL 模式 + `better-sqlite3` 同步 API，写入延迟 < 1ms。

### 5.4 数据模型（核心）

```typescript
// 项目
interface Project {
  id: string;
  title: string;
  genre: string;
  logline: string;
  rootPath: string;          // 本地项目目录
  createdAt: number;
  updatedAt: number;
}

// 卷 / 章节
interface Volume { id: string; title: string; order: number; }
interface Chapter {
  id: string;
  volumeId: string;
  title: string;
  filePath: string;          // 相对 rootPath 的 .md
  outline: string;
  wordCount: number;
  status: 'draft' | 'done' | 'published';
  order: number;
}

// 人物卡
interface Character {
  id: string;
  name: string;
  aliases: string[];
  age?: number;
  appearance: string;
  personality: string;
  abilities: string[];
  relations: { targetId: string; type: string; note: string }[];
  firstAppearChapterId?: string;
  lockedFields: string[];    // 锁定字段，Agent 不可修改
}

// 伏笔
interface Foreshadowing {
  id: string;
  description: string;
  plantedAt: { chapterId: string; offset: number };
  resolvedAt?: { chapterId: string; offset: number };
  status: 'pending' | 'resolved' | 'abandoned';
}

// Agent 会话
interface AgentSession {
  id: string;
  projectId: string;
  type: 'outline' | 'writer' | 'polish' | 'review';
  messages: Array<{ role: string; content: string; ts: number }>;
}
```

### 6.2 关键交互
- `⌘K`：命令面板（任何操作）
- `⌘Enter`：续写下一段
- 选中文字 → `⌘L`：润色
- `⌘⇧F`：全屏沉浸写作模式（打字机滚动）
- `⌘.`：召唤 Agent 行内建议（Cursor Tab 风格）
- 右键章节 → "审校本章" / "生成小结"
- 保存时后台增量 Embedding + 轻量审校（不阻塞）

### 6.3 写作模式（核心体验）
- 隐藏所有侧栏，居中固定栏宽
- 打字机模式：当前行永远在视口中间
- 背景音（雨声 / 咖啡馆）可选
- 目标字数进度条，完成有庆祝动画
